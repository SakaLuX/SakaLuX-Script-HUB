# SakaLuX Halloween Assistant

## Current version
**v0.2.7**

## Purpose
SakaLuX Halloween Assistant is a mobile-first Torn helper that finds live, attack-ready Halloween targets and ranks the easiest estimated defeats first.

## Features
- Shows only targets verified as **LIVE OKAY**.
- Prioritizes targets with an active bounty, then fills the list with suitable targets without bounty.
- Sorts the easiest and fastest estimated defeats first.
- Displays Fair Fight, estimated battle stats, level and bounty information when available.
- Direct **ATK** and profile buttons.
- Configurable board pages, maximum FF, result count and live checks.
- Uses short-lived caches and concurrent requests for faster rescans.
- Separate API-key panel with Torn/Script Hub key support and optional FFScouter key.
- Movable floating launcher with saved position.
- Compact mobile panel without background blur.
- Shared SakaLuX Core integration.
- Dedicated **🇷🇴 Special for REK family 🪖** item-support button.

## API and privacy
The script can use the Torn API key already exposed by SakaLuX Script Hub/TornPDA or a key saved locally in the Halloween Assistant panel. An optional FFScouter key can improve target estimates. Locally entered keys stay in browser/TornPDA storage.

## Important
Attack decisions remain manual. The script does not automatically attack players or control weapons. Fair Fight and battle-stat values are estimates and do not guarantee a win.
