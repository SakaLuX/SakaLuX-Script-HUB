# Gym Optimizer v1.4.0

- New manual refresh of user perks, gym, bars and battle stats from Torn using the shared Hub API key.
- Display all gym-related returned perk categories, API freshness, energy and DEX-specialist ratio context.
- Rep planning uses verified native energy-cost attributes where present; no assumptions when absent.

Known limitations: exact perk stacking, full training gain formula, next-gym remaining XP/ETA and special eligibility need verified API schemas and testing with TornPDA. The script does not claim those are complete.
