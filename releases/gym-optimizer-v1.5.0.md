# Gym Optimizer v1.5.0

Adds approximate gym-gain estimates from documented wiki formula, per-stat parseable perks, DEX 1.25 headroom and conditional next-gym ETA based on validated API data.

If actual remaining Gym EXP and verified E/day are absent, the UI explicitly says ETA unavailable. Exact gains, full perk stacking, and all special gym eligibility must be validated with real Torn API v2 responses before enabling automatic training decisions.
