# Gym Optimizer v1.0.0 (2026-10-20)

Initial standalone Gym planning MVP. Editable strategy templates: Balanced, 2-stat, 3-stat, Baldr, Hank, Aec3, Custom. Manual stat entries and local snapshots. Does not switch gyms automatically. Does not treat unknown/unlocked status as true. Exact StatForge parity, Hub control integration and gym unlock tracking remain future work.
