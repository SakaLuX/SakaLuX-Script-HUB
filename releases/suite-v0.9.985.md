# SakaLuX Suite v0.9.985

Released: 2026-10-20

## Lottery Max Buy

- Adds a dedicated Casino module for Daily Dime, Lucky Shot Lotto and Holy Grail.
- Detects the available Casino Token count and adds a compact `MAX BUY` control beside Torn's ticket quantity field.
- Fills the maximum ticket quantity using native input/change events for Torn's reactive interface.
- Keeps the final purchase manual: the player must still press Torn's own purchase button.
- Supports Torn PDA navigation and dynamically rendered lottery forms.
