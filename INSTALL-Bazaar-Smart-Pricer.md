# Install — SakaLuX Bazaar Smart Pricer

Raw userscript:
`https://raw.githubusercontent.com/SakaLuX/SakaLuX-Script-HUB/main/SakaLuX-Bazaar-Smart-Pricer.user.js`

Open the raw URL in TornPDA/Tampermonkey/Violentmonkey, install the script, open Torn Bazaar, then tap **S Smart Pricer**. Add a Torn read-only/public API key, choose the pricing mode, save settings, then use **S PRICE** on one row or **PRICE ALL VISIBLE** for the rendered Bazaar rows.

Torn still requires the player to review and submit/save the final Bazaar changes.
