# Install — SakaLuX Bazaar Smart Pricer

Canonical userscript:
`https://raw.githubusercontent.com/SakaLuX/SakaLuX-Script-HUB/main/SakaLuX-Bazaar-Smart-Pricer.user.js`

Install in TornPDA/Tampermonkey/Violentmonkey. Open Bazaar: the Quick Pricer-style per-item controls and draggable Quick Fill/Settings chip will initialize automatically. The same Settings panel is also available from SakaLuX Script Hub.
